Системы контроля версии Кочеткова Арина

Цел работы: научиться использовать систему контроля версий GIT для управления локальным и удалённым репозиторим, освоить создание веток, слияние изменений, а также размещение сайтов на GitHub.
ход работы:
1. Установили GIT.
2. Создали локальный репозиторий.
3. Создали файл отчета по выполнению практической работы и поместили его в репозиторий
4. Зафиксировали в отчете все проделанные шаги и создали версию отчета в GIT
5.Создали ветку отчета `rep`, добавили описания шагов в отчет и создали версию отчета в новой ветке.
6.  Ветка `rep` успешно слита с основной веткой `main` командой `git merge`.
7.  Создан проект `homework-IIT2` на GitHub. Локальный репозиторий загружен на удалённый сервер с помощью команд `git remote add` и `git push`.
8.  В репозиторий добавлены файлы статического сайта и активирован GitHub Pages для его публикации.
9.  Отчёт завершён.
